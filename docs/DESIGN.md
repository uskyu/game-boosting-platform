# 设计系统规范 · Design System v2

> 本文档是本项目 UI 的**唯一视觉规范**。任何代理或开发者改动前端样式前必须完整阅读本文档，改动后必须逐条通过第 9 节的验收清单。审美基调：**苹果式克制（Apple HIG 风格）**——内容优先、留白呼吸、层级靠排版而非重装饰、亮暗双主题一等公民。

---

## 1. 设计原则（不可妥协）

1. **内容优先**：装饰服务于信息，页面永远先呈现"用户要看的数字/订单/状态"，装饰元素不得抢视觉焦点。
2. **留白呼吸**：区块间距宁大勿小；禁止把卡片挤成一堵墙。主内容区最大宽度 1280px 居中。
3. **层级靠排版**：字号、字重、颜色深浅三级表达层级；禁止用大面积色块/渐变制造层级。
4. **色彩克制**：一个页面同时出现的强调色 ≤ 2 种；品牌主色只用于主 CTA、active 态、关键数字。
5. **圆角与阴影一致**：同一层级的元素圆角、阴影完全一致；阴影永远"轻"（亮色下几乎看不见存在感）。
6. **动效微而短**：150–250ms，仅用于反馈（hover/focus/入场），不做炫技动画。
7. **亮暗双主题同时验收**：任何样式改动必须亮色、暗色两态都截图检查；暗色不是亮色的"反色"，是独立调校。

## 2. 主题系统（CSS 变量双主题）

实现方式：全部颜色经 CSS 变量引用；`:root` 为亮色值，`html.dark` 覆盖为暗色值。Tailwind `darkMode: 'class'`。

### 2.2 主题切换

- 位置：桌面顶栏右侧 + 移动端"我的"页设置区。
- 三态：`light / dark / system`（跟随系统，默认值）。图标：太阳 / 月亮 / 自动（显示器小图标，内联 SVG，不用图标库）。
- 持久化：`localStorage['theme']`；`system` 模式监听 `matchMedia('(prefers-color-scheme: dark)')` 变化实时切换。
- **防闪烁**：`index.html` `<head>` 内联脚本，渲染前读取 localStorage 并给 `html` 加 `dark` class（无值时跟随系统）。
- 切换过渡：`html { transition: background-color .2s }` 级别即可，禁止全页 transition-all。

## 3. 排版

- 字体栈：`-apple-system, BlinkMacSystemFont, "SF Pro Text", "PingFang SC", "Microsoft YaHei", system-ui, sans-serif`（写进 tailwind fontFamily 与 body）。
- 字号阶（px）：12 / 13 / 15（正文默认）/ 17 / 20 / 24 / 28 / 34（页面大标题）。行高 1.5，标题 1.2。
- 字重：常规 400 / 中 500 / 半粗 600 / 粗 700。**中文禁用 800+**。
- 数字（金额、统计）使用 `font-variant-numeric: tabular-nums`；大金额用 24–28px semibold + `--price` 色。
- 页面标题统一结构：小 eyebrow（12px、`--text-3`、字距 0.06em 大写/轻中文）→ 大标题（24–28px, 600）→ 可选副文案（15px, `--text-2`）。

## 4. 几何与间距

- 场次圆角：输入框 `10px` / 小卡 `14px` / 卡片 `18px` / 大面板与弹窗 `22px` / 按钮与标签 `999px`（胶囊）。
- 间距网格：4px 基数；卡片内边距 `20px`（移动 16px）；区块间距 `24–32px`。
- 主容器：`max-width 1280px`，水平 `padding 24px`（移动 16px）。
- 阴影（亮色为主视觉基准）：
  - 卡片静态：`0 1px 2px rgba(0,0,0,0.04)`
  - 卡片 hover：`0 4px 12px rgba(0,0,0,0.08)`
  - 弹窗：`0 24px 60px rgba(0,0,0,0.18)`
  - 暗色下：阴影改为"边框发光感"——用 `border-color` 提亮 + 极弱阴影，不用大面积投影。

## 5. 组件标准（亮/暗两态都必须达标）

| 组件 | 标准 |
|---|---|
| 主按钮 | 胶囊、`--primary` 实底、白字、高 44px、hover 提亮 8%、active 缩放 0.97、disabled 40% 透明 |
| 次按钮 | 胶囊、`--surface-3` 底、`--text-1` 字 |
| 幽灵按钮 | 无底、`--primary` 文字、hover `--primary-soft` 底 |
| 危险按钮 | 同主按钮但 `--danger` |
| 卡片 | `--surface` 底 + `1px var(--line-1)` 边 + 4.1 阴影；hover 仅上浮 2px + hover 阴影；**禁用渐变底** |
| 输入框 | `--surface-3` 底、无边框、focus 时 `2px --primary` 外圈（box-shadow ring）+ 底色变 `--surface` |
| 下拉 | 同输入框；自绘箭头；option 深色浮层（暗色下同色）|
| 状态标签 | 胶囊小标签：语义色 10–14% 透明底 + 同色系文字 + 无边框。四态：待处理(黄)/待打款(蓝)/已打款(绿)/已驳回(红) |
| 表格/列表行 | 无斑马纹；行高 ≥ 44px；hover `--surface-2`；分隔线 `--line-1` |
| 弹窗 | 遮罩 `rgba(0,0,0,0.4)` + `backdrop-blur(8px)`；面板 `--elevated`、圆角 22、入场 200ms 上移淡入 |
| 空状态 | 居中：48px 灰色内联 SVG 图标 → 主文案 17px `--text-1` → 次文案 13px `--text-2`；**禁止大面积插画背景** |
| 骨架屏 | `--surface-2` 底块 + 微光扫过动画（20% 透明度白光）；列表用 3–4 行块 |
| 统计卡 | 数字大（24px semibold tabular-nums）+ 标签小（13px `--text-2`）；**默认白卡同款式，仅数字颜色区分语义**（可用余额=--text-1、收入=--success、提现=--text-1、冻结=--warning）；禁止彩色渐变卡 |

## 6. 信息架构（IA v2）

**核心原则：订单大厅是产品的心脏，`/` 就是大厅。**

- `/` = **订单大厅**（原 OrderList 强化为大厅版，路由名 `home`）
  - 顶部：统计条（待接单 / 进行中 / 今日完成，数字大字）+ 游戏筛选 + 状态筛选（一行放下）
  - 主体：订单卡网格（桌面 2 列、平板 1.5、移动 1 列）
  - 订单卡信息层级：**价格最大最显眼（--price 红、tabular-nums）** → 游戏名 + 状态标签 → 目标段位/时间 → 打手视角主 CTA"立即抢单"（--primary 实底胶囊，卡片右下）
  - 空态与大数字空态友好
- `/games` = 游戏专区（原 HomeView 内容收敛为次级页面，网格精选 + 分类，权重降低）
- 导航（桌面顶栏）：**大厅** · 游戏 · 钱包 · 消息 · [运营(仅管理员)] + 右侧搜索/主题切换/用户
- 移动端底部 Tab（固定 5 个）：**大厅 · 游戏 · 钱包 · 消息 · 我的**；顶栏只留品牌 + 搜索 + 主题切换
- 旧 `/home` 路由 301 到 `/`；旧入口全部改指新路由

## 7. 移动端适配规范

- 断点：`sm 640 / md 768 / lg 1024`；主布局在 `< md` 时单列。
- 底部 Tab：高 56px + `env(safe-area-inset-bottom)` 内边距；毛玻璃底（亮：`rgba(255,255,255,0.82)+blur`；暗：`rgba(28,28,30,0.82)`）；图标 24px + 10px 文字标签；active 用 `--primary`。
- 触控目标 ≥ 44×44px；表单字段高 44px；卡片间距 12px。
- 订单大厅移动版：筛选条横向滚动（scroll-snap 可选）；统计条两列紧凑排。
- 弹窗在移动端改为底部滑出面板（圆角只留顶部 22px）。
- 主内容区移动 padding 16px。

## 8. 动效

- 统一 `150ms / 200ms` + `cubic-bezier(0.4, 0, 0.2, 1)`；仅 hover / focus / 入场 / 主题切换四类。
- 列表入场：整体淡入 150ms，不做逐项 stagger。
- 数字变化（余额刷新）：不做数字滚动动画（克制）。

## 9. 验收清单（每次 UI 改动后逐条打勾）

1. `npm run build` 零报错；`npm test` 全过。
2. 亮色模式：首页（大厅）/ 订单卡 / 钱包 / 管理后台 / 登录页截图检查——背景层级清晰（`#f5f5f7` 页底 vs 白卡对比可辨）、无残留深色块、无色彩冲突。
3. 暗色模式：同上五页截图检查——黑底 `#000`、卡片 `#1c1c1e`、文字对比度充足、无刺眼纯白大块。
4. 主题切换：切到 dark 无闪烁（刷新不跳白/黑）、system 跟随系统、刷新后保持。
5. 全站无硬编码色值（`grep -rE '#[0-9a-fA-F]{3,8}' src --include=*.vue` 仅允许出现在 token 定义文件与游戏图片映射）；页面/组件一律用语义类或变量。
6. 导航与 Tab 单行不折行；移动端底部 5 Tab 齐全可点。
7. 订单卡在 `375px` 宽度下单列不溢出、价格醒目、CTA 可触达。
8. 空状态、加载骨架屏两种主题下都正常。
9. 按钮四档（主/次/幽灵/危险）与标签四态样式统一。
10. 弹窗遮罩模糊、圆角、入场动画正常。
11. 滚动条样式两种主题都协调。
12. 手机端（DevTools 375×812 模拟或窄窗口）逐页无横向滚动条。

## 10. 执行代理须知（给后续干活的你）

- 本文档优先级高于任何既有代码样式；与旧样式冲突时**以本文档为准重写**。
- 改动尽量落在：`tailwind.config.js`（token）、`src/assets/main.css`（组件类与变量）、`src/stores/settings.js`（主题状态）、`index.html`（防闪烁）、各视图模板的类名替换。
- 禁止引入图标库/UI 框架；图标一律内联 SVG（stroke 1.5–2px，round cap，20–24px）。
- 每完成一个阶段先跑第 9 节 1、5 两项，全部完成后跑完整清单。
