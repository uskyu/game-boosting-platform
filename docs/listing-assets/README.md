# 上架素材（闲鱼 / 软件售卖平台）

本目录存放用于**软件售卖平台上架展示**的产品截图，可直接交给运营/美工做排版、加文案和尺寸适配。

- **版本**：当前主线 `0801fda`（含指定派单、指定单标识、保证金、浮动聊天等能力）
- **来源**：本地演示环境（独立演示库 `game_boosting_market_demo`，前端 `127.0.0.1:3000`）
- **数据**：全部为虚构演示数据，品牌名「竞界」，用户「小陈 / 阿良 / 阿凯 / 小北 / 阿哲」，邮箱均为 `demo.example.com`
- **隐私**：不含真实用户账号、真实邮箱、生产服务器地址或密钥；截图中的订单、金额、聊天内容均为演示用途

## 排版建议

- **首图/封面**：`01_cover_hall.png`，可叠加一句主标题，例如「游戏代练 · 陪玩 · 护航一站式平台」。
- **产品亮点（9 图内）**：`04`、`05`、`06`、`07` 放在前面讲「指定派单」；再配 `02`、`03`、`10`、`13`、`17` 覆盖大厅、移动端、资金与后台。
- **详情长图**：`17`~`24` 适合做后台能力长图；`09`、`12`、`14` 适合做手机端长图。
- **尺寸**：图片均为 PNG，桌面端宽 1440/1920，手机端宽 780（390 逻辑像素 @2x），可直接等比缩放。

## 可售功能点（供写详情页参考）

- 订单大厅：公开抢单、指定派单、多名额订单、接单等待/保证金档位
- 发单托管：发单冻结、到账时效、结单审核、售后与争议处理
- 打手侧：接单、交付截图、聊天沟通、钱包结算、提现、保证金权益、服务卡
- 客户端：订单进度、消息中心、每日排行榜、移动端适配
- 后台：数据看板、派单/用户/游戏/提现/售后/服务费/保证金/站点设置、批量打款
- 安全与运营：注册/接单验证码、同时在线设备限制、发单权限审批、黑名单、公告

## 说明

- 截图中的「竞界」为演示品牌名，正式售卖时可改为自己的品牌后重新截图（后台「站点管理」可直接改名称和简介）。
- 若平台要求图片尺寸不同，可按比例裁剪；需要横版封面、九宫格或带手机壳的合成图，可在本目录基础上让美工加工。
